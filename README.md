## Machine Learning Phishing Email Detector

A Python-based phishing email detection system which analyses screenshots of emails, extracts textual content using Optical Character Recognition (OCR), and estimates phishing risk using a neural network implemented from first principles.

After completing Google's Cybersecurity Professional Certificate, I became interested in how machine learning techniques could be applied to cybersecurity problems. Rather than relying on existing machine learning frameworks, this project explores the underlying mechanics of neural networks by implementing model training, weight optimisation, activation functions and prediction logic from scratch.
